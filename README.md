# ConcordUIExamples

<https://github.com/Zodiac-Innovations/ConcordUIExamples>

Example applications showing ConcordUI on Apple and Android.

| Example | What it shows |
| --- | --- |
| [HelloConcordUI](HelloConcordUI/) | A minimal shared Swift application that displays “HelloConcordUI.” |
| [ElementShowcase](ElementShowcase/) | Interactive examples of stacks, labels, buttons, text and numeric inputs, booleans, dates and times, selections, images, icons, raster layouts, and platform-specific UI. [Screenshots](ElementShowcase/Screenshots/) |
| [FeaturesShowcase](FeaturesShowcase/) | Standard Welcome, Get Started, What’s New, About, Settings, FAQ, and Help experiences. [Screenshots](FeaturesShowcase/Screenshots/) |
| [PlatformShowcase](PlatformShowcase/) | Platform information and capabilities, including native actions, audio and speech, storage, embedded files, and platform elements. [Screenshots](PlatformShowcase/Screenshots/) |
| [PresentationShowcase](PresentationShowcase/) | Presentation metadata and element trees, editable presentation data, display options, lifecycle callbacks, and a presentation hosted in a secondary venue. |
| [VenueShowcase](VenueShowcase/) | Main and secondary venues, registered presentations, and dialog or sheet modal venues attached to either venue. |

Each application has shared Swift code in `Shared/Swift` and Apple and Android projects in its own directory. The screenshot folders show the current output for the three examples linked above.
